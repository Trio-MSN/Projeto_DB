Game Library – Biblioteca de Jogos

Sobre o projeto

O Game Library é um projeto de desenvolvimento web que tem como objetivo criar uma biblioteca de jogos com três telas, incluindo um sistema de login e integração com banco de dados.

Tecnologias utilizadas
Next.js
Node.js
TypeScript
HTML
CSS
MySQL

Integrantes

Objetivo

Colocar em prática os conhecimentos de desenvolvimento web e banco de dados, trabalhando com criação de telas, sistema de login e integração com MySQL.

Projeto acadêmico desenvolvido para fins educacionais.
